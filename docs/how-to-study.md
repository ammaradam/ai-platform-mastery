# How to study this curriculum

## The budget

- **Modules:** ~190 hours. **Capstones:** ~15–20 hours each (~100 hours).
- At **6–7 hours a week**, that's about **12 months**.
- Suggested rhythm: two weekday evenings (1.5 h each) plus one weekend block (3 h).

## The 12-month plan

| Weeks | Focus | Output |
|---|---|---|
| 1–2 | **P1 test-out.** Take all four P1 quizzes cold. Only study the modules you fail | P1 capstone (ML Test Score review of Beacon) |
| 3–12 | **P4 Evals + observability** (your biggest gap) | Eval-gated agent + blog post + Malaysian eval set v0 |
| 13–21 | **P3 Inference + GPU economics** | vLLM benchmark + cost study + blog post |
| 22–32 | **P2 Platform + Kubernetes** | Reference platform repo + blog post |
| 33–40 | **P5 Governance + security** | Governance pack + threat model |
| 41–52 | **Consolidate.** Talk submissions, MLOps-Toolbox release, review missed quiz questions | Talk delivered, public body of work |
| Throughout | **P6** — one post a month, one ADR per real decision | |

## The method for each module

1. **Quiz first (5 min).** Take the quiz cold to see what you already know. Don't look up answers.
2. **Lesson (30–45 min).** Read actively. After each section, close it and explain it out loud in two sentences (Feynman technique).
3. **Required readings.** Read with the "Focus on" note in mind. Write three bullet takeaways per reading in the app notes.
4. **Quiz again.** Pass at 80% to unlock the next module. Read every explanation, including for questions you got right.
5. **Core exercises.** These are where the learning sticks. Push the work to your own repos and paste the links into the app.
6. **Reflection.** One honest paragraph, tied to your real work at Pickles.

## Remembering it

- The app's **Review** tab resurfaces questions you got wrong. Clear it weekly.
- Re-take a finished pillar's quizzes a month later. If you drop below 80%, re-read that lesson.
- Teaching beats re-reading: each capstone ends in a public write-up (P6).

## Rules that keep you on track

- **Finish before you widen.** Pause side projects that don't feed this story (platform + evals + Malaysia).
- **Real data over toy data.** Use Pickles systems where you're allowed to; otherwise PriceCatcher or other public Malaysian data.
- **Write it down as you go.** Every exercise is a future blog post, talk slide or interview story.
- **Check facts that change.** Regulations, tool versions and benchmarks move. Lessons flag where; verify before you rely on them in public.
